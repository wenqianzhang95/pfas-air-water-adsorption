# Data and code for: Adsorption of ionic PFAS at the air-water interface at low concentrations

Authors: Wenqian Zhang and Bo Guo, Department of Hydrology and Atmospheric Sciences, University of Arizona.

**Status: private repository, preparation stage, last synchronized with the manuscript source on 28 October 2026. No public release or DOI has been assigned yet.** Code is released under the MIT License (`LICENSE`); authored data, figures and documentation under CC BY 4.0 (`LICENSE-DATA`). ## Reproducing Figure 4

Python 3.10 or newer is required. Install the requirements and run from `code/adsorption`:

```text
python -m pip install -r requirements.txt
cd code/adsorption
python plot_selected_pfas_master_curve.py --output-dir ../../results/fig4
```

On a headless machine set `MPLBACKEND=Agg`. The script writes `fig5_full_vs_langmuir.{pdf,png,svg}` (the file name follows the manuscript's figure file, which corresponds to compiled Figure 4) and `source_data/fig4/*.csv`.

Clean-environment check (28 October 2026, fresh Python 3.13 virtual environment with numpy 2.5.4, pandas 3.1.0, scipy 1.18.1, matplotlib 3.11.2): the script ran to completion and the regenerated `fig4_parameters.csv`, `fig4_a_f_measurements.csv` and `selected_pfas_minimum_ratio.csv` were byte-identical to `data/fig4/`; `selected_pfas_master_curve_linearity.csv` differed only in the last digit of one floating-point value (1e-17). The numeric comparison of the two large curve files is recorded in `docs/RELEASE_CHECKLIST.md`, section D. `fig4_h_empirical_fit_summary.csv` is produced by a separate step and is not regenerated by this entry point.

## Transport model dependency

The MATLAB code calls the MATLAB Reservoir Simulation Toolbox (MRST 2022a, GPL-3.0, https://www.sintef.no/projectweb/mrst/), which is not redistributed here. `code/transport/setpath.m` expects an `mrst-2022a` directory next to the scripts. The MATLAB version used for the archived runs and a clean-installation test are still to be documented (checklist item A6/B4).
