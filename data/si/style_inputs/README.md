# Recorded inputs for the SI figure style revision

The companion plotting script changes styling without refitting parameters.

- S2: the original surface-tension routine was used for a numerical-only export. The visible model polyline was checked against the original PDF vector path (maximum interior discrepancy below 0.00002 PDF points). Original parameters and concentration grid were retained.
- S4 and S5: unchanged pointwise surface excesses and squared base-10 logarithmic errors from the archived evaluation CSV. Original vector polylines were cross-checked.
- S6: original full-data and trimmed-data fit parameters, observations and 72-point concentration grids. No new fit.
- S7: saved electrical-potential arrays from the original plot and the original surface-tension expression. These preserve that figure's existing parameterization; the potential was not recomputed.
- S9: archived boundary coordinates and the unchanged classification equations on the original grid.

The style JSON records palette values from the scientific-figure-aesthetics skill. Mass-action predictions use blue; Szyszkowski–Langmuir predictions use terracotta; measurements use neutral symbols. Line style also distinguishes models. Original source data and earlier figure PDFs are preserved separately.
